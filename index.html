退会・休会・種目変更

退会はフォームからお申し込みください。

【退会・休会・変更申請フォーム】

締め切りのルール

・毎月 15日まで の申請 → 当月末退会

・16日以降 の申請 → 翌月末退会（翌月分の月謝が発生します）

※例）8/15に退会申込みの場合 → 最短8月末退会
※例）8/16以降に退会申込みの場合 → 最短9月末退会

休会も同じフォームからお申し込みください。

【退会・休会・変更申請フォーム】

締め切りのルール（退会と同じです）

・毎月 15日まで の申請 → 当月末から休会

・16日以降 の申請 → 翌月末から休会

※例）8/15に休会申込みの場合 → 最短8月末から休会
※例）8/16以降に休会申込みの場合 → 最短9月末から休会

種目変更はフォームからお申し込みください。

【退会・休会・変更申請フォーム】

翌月1日付けでの切り替えとなります。

申し訳ありませんが、16日以降のお申し込みは翌月末退会となり、翌月分の月謝も発生します。

スポスル・お支払い

当月末までにお支払いください。

請求書は毎月25日に発行されます。月末までに決済が完了しない場合、翌月分のお支払いも発生しますので、お早めにお手続きください。

承認と同時にスポスルから自動送信メールが送られ、その内容にスクールIDが記載されています。届いていない場合は、一度迷惑メールボックスや他のボックスに振り分けられていないかご確認ください。

※スポスルからの承認メールが届かない場合は、入会後に届いた参加決定通知メールに記載がございますのでご確認ください。

ログインの手順

  1. 運営からの承認を待つ
  2. 承認されるとスポスルから自動でメールが届く
  3. メールを開き、スクールIDを確認する
  4. アプリを開き、メールアドレスとスクールIDを入力する
  5. パスワードを設定する（初回のみ）
  6. ログイン完了

メールが見つからない場合や、それでもログインできない場合は運営までご連絡ください。
📧 sanwa.x.energy@gmail.com
